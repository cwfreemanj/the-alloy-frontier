D (M1–M3) are passed (see [GDD-v0.5.md](GDD-v0.5.md)). This page tracks M4 to sign-off: what
is met, the evidence, and what each partner still has to do.

**Build under test:** the live game at https://alloy-frontier.onrender.com. The build is shown on
the title screen and in the pause menu, for example `v0.1.0 (6ff3324, 2026-11-25)`. Note it with
every result.

## 1. Three fresh playthroughs

Each one needs a **new character**. Use your account's second slot: on the title screen, type a name under **Character 2**, then **Create character**. Names are unique, so pick one nobody has. Your first character stays in slot 1. To run another fresh playthrough later, delete Character 2 (the card asks you to type DELETE) and create it again. Play from the
start to the quest summary, without debug shortcuts.

**How:** follow [PLAYTEST.md](PLAYTEST.md). Note the time, deaths and anything confusing. Answer:

- **F1:** Did you always know what to do next?
- **F2:** Did the forge make sense the first time? Which step, if any, was confusing?
- **F3:** Could you feel the difference between your Quick Forge and Masterwork swords in a fight?
  Did the specialization you chose change how fights played?
- **F4:** Was the Warden beatable with fair play? How many tries did it take?
- **F5:** Did you finish wanting another recipe, area or weapon? (GDD 12.10)

## 2. Performance on the target machines

On each partner's own computer:

1. Open the live game in a normal browser window (Chrome or Edge), at your usual screen size.
2. Leave the graphics preset as it is (medium is the default) and play for a few minutes.
3. Stand on the Ironwood Trail for 15 seconds without moving.
4. Press **Esc**, then click **Copy performance report**. The report covers the last ~10 seconds.
5. Paste it into a new file `docs/perf/<date>-<machine>.md`, or send it over to be added.
6. Optional: switch to the low preset, repeat steps 3–5, and include both.
